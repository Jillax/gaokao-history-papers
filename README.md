# 新高考历史历年真题开放资料库

2015 年 10 月至 2026 年各省新高考历史试卷归档、检索与下载，附六维评价细则与 Top 20 精选榜单。

## 在线浏览与检索网站

- 若已开启 GitHub Pages，可直接访问站点首页进行**按省份/年份/格式筛选、在线预览与下载**。

## 仓库目录导览

- [试卷目录.md](试卷目录.md)：2015–2026 年 131 套新高考历史卷逐场档案与来源索引
- [新高考历史卷 Top 20.md](新高考历史卷%20Top%2020.md)：综合排名与六维评析
- [六维评分细则.md](六维评分细则.md)：考查布局、史料运用、历史推理、设问质量、任务梯度、开放论证评分标准
- [原卷/](原卷)：已归档的 PDF / HTML / DOCX / Markdown 试卷文件
- [雷达图/](雷达图)、[雷达图_14档Top3/](雷达图_14档Top3)、[雷达图_评测版/](雷达图_评测版)：各卷六维评分雷达图
- [site/](site)：零构建依赖的静态检索下载网站源码
- [DEPLOYMENT.md](DEPLOYMENT.md)：静态网站与国内对象存储（OSS/COS）部署指南

## 更新网站数据

新增或修订 `试卷目录.md` 后，在仓库根目录运行：

```bash
python scripts/build_site_data.py
```
