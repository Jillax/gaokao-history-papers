## 试卷基本结构

- **满分**：100 分；**考试时间**：60 分钟。
- **题型布局**：20 道选择题（每题 2 分，共 40 分）＋ 3 道综合题（共 60 分），全卷共 29 题（第三大题含第 27—29 小题）。
- 试卷以唯物史观统领，注重时空观念、史料实证、历史解释等核心素养；选择题部分"儒家思想""《共产党宣言》"等题提供史料考查信息提取，并以数据柱状图呈现"新中国的三次建交高潮"。

## 三大综合题主题（考试院官方评析披露）

1. **走向整体的世界**
   - 以时序板块结构、提纲形式整理世界自 15、16 世纪以来从分散走向整体的过程，内容涵盖"新航路的探索与开辟""工业社会的来临""资本主义世界体系的形成""两次世界大战""国际联盟与联合国""经济全球化"等重大史事。
   - 在"15—16 世纪""17—19 世纪""20 世纪上半叶""20 世纪中期以来"四个递进的大跨度时段中集约所学，于大视野下展示历史时空流变，突出时空观念素养。

2. **史事的面相（探究"汉武盛世"）**
   - 以开展专题讲座的形式探究"汉武盛世"的面相，从证据的角度解释历史、探究历史，培养史料互证意识，加强史料实证考查。

3. **上海的两次"开放"（25 分）**
   - 将现实热点与知识重点结合，认识上海在近现代历史中的特殊地位和重要作用，培养历史解释素养，坚定改革开放信念，涵养家国情怀。全文节选见下。

**（三）上海的两次"开放"（25 分）**

近代以来，上海先后经历了两次"开放"，城市地位发生了翻天覆地的变化。

**材料一** 开埠后不久，时人观察到："（上海）适介南北之中，最为冲要，故贸易兴旺，非他处所能埒（等同）。""民生日盛，生计日繁，金山银穴，区区草县，名震天下。"五十年间，上海进出口贸易总值平均占全国的一半以上。1850 年，上海的出口商品中，蚕丝占 51%，茶叶占 46%；1860 年，蚕丝占 66%，茶叶占 28%。1892 年，英国驻沪领事指出：在中国向外开放后的许多年来，对外国出口的商品几乎只有丝茶两种。

——引自周武《边缘缔造中心：历史视域中的上海与江南》

**材料二** 新中国建立后，上海完成了向社会主义计划经济的过渡，转变为制造业为主的"工业基地"，但因处于封闭半封闭状态，长期形成的对外贸易优势无法得到充分发挥。70 年代后期，党中央提出实行改革开放。邓小平说："关起门来，固步自封，夜郎自大，是发达不起来的"，必须"实行开放政策"。上海由此迎来了又一次开放的大潮。

上海开放大事记：

| 年份 | 事件 |
| --- | --- |
| 1978 | 上海开辟至澳大利亚远洋运输航线，打破我国集装箱运输零的记录 |
| 1980 | 上海第一家中外合资企业成立 |
| 1990 | 中央决定以上海浦东开发开放为龙头，进一步开放长江沿岸城市 |
| 2001 | 中央提出把上海建成现代化国际大都市和国际经济、金融、贸易、航运中心 |
| 2006 | 上海港成为世界最大的货运港口 |
| 2010 | 上海世博会开幕，成为展示中国发展巨变和深化国际合作的平台 |
| 2013 | 国务院正式批准设立中国（上海）自由贸易区 |
| 2018 | 上海推出"扩大开放 100 条"；首届进口博览会开幕 |

- **27.** 根据材料一，概括开埠给上海带来的影响。（6 分）
- **28.** 根据材料二，概述上海第二次开放的背景和成果。（4 分）
- **29.** 结合材料及所学，你如何看待上海的两次"开放"？（15 分）
